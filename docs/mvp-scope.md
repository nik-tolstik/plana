# Plana — скоуп MVP (финальный)

Утверждён владельцем 2026-10-09. Основание: `docs/research/ticktick-features.md`, `docs/decisions.md`. Этот документ — канонический список того, что входит в MVP. Всё, что не перечислено здесь, — вне MVP.

## 1. Аккаунт и профиль

- Регистрация и вход: email + пароль (argon2, access-JWT + refresh-токены в БД с ротацией) и Google OAuth — оба способа с первого релиза.
- Профиль: имя, email, таймзона.
- Тема оформления: 3 режима — системная (следует `prefers-color-scheme`) / светлая / тёмная; выбор хранится в профиле и localStorage.

## 2. Задачи (ядро)

- CRUD задач, отметка выполнения, возврат из выполненных.
- Атрибуты: заголовок, описание (Markdown), приоритет (высокий/средний/низкий/нет), дата и время (или «весь день»), теги, закрепление (pin), привязка к списку.
- Повторяющиеся задачи: ежедневно/еженедельно/ежемесячно/ежегодно + кастомные правила (интервалы, дни недели, до даты / N повторений). RRULE, вхождения в таймзоне пользователя.
- Подзадачи (checklist) с ручным порядком.
- Быстрый ввод с NLP-парсингом дат и повторов (русский язык: «завтра в 17», «каждый пн»).
- Ручной порядок drag&drop + автосортировка (по дате / приоритету / названию).
- Массовые операции (выделить несколько: переместить, удалить, завершить).
- Корзина: удалённые задачи и списки восстановимы.

## 3. Организация

- Списки (проекты): имя, цвет, эмодзи/иконка, ручной порядок.
- Папки для группировки списков.
- Секции внутри списка (группировка в list view).
- Смарт-списки: Inbox, All, Today, Tomorrow, Next 7 Days, Recent, Completed, Trash.
- Поиск по заголовкам, описаниям, тегам.

## 4. Представления

- List view — единственное представление: группы по дате/приоритету/тегу/списку/секции, сворачиваемые группы, drag&drop между группами.
- Desktop: раскладка «сайдбар + список + панель деталей». Mobile: список + переход к деталям, нижняя навигация.

## 5. Напоминания и уведомления

- Напоминания по времени у задачи (одно или несколько).
- Доставка: web push (service worker + VAPID; iOS 16.4+ для установленных PWA, Android Chrome, desktop Chrome/Edge/Firefox).
- Отправка: cron-воркер на Railway (без Redis) ищет наступившие напоминания и шлёт push.
- Разрешение на push запрашивается при создании первого напоминания, не при загрузке приложения.

## 6. Привычки

- Создание привычек: название, тип «чек» или «число», расписание (дни недели), цвет.
- Ежедневные чек-ины (для «числа» — значение), отметка «выполнено/пропущено» за прошлые дни.
- Стрики, календарь-журнал выполнения за месяц.
- Отдельный раздел в приложении.

## 7. Вложения

- Файлы у задачи: изображения и документы.
- Лимиты: до 10 МБ на файл, до 100 МБ на пользователя (уточнить при проектировании API).
- Загрузка напрямую из браузера по presigned URL в Railway Object Storage; API хранит только метаданные.

## 8. PWA

- Инсталляция (manifest, иконки, standalone-режим) на desktop и mobile.
- Service worker — минимальный: инсталляция + приём web push. Офлайн-режим с локальными данными — post-MVP.

## 9. Прочее

- Тёмная/светлая/системная тема (см. профиль).
- Горячие клавиши + command palette (базовые: быстрый поиск, создание задачи, навигация).
- Sentry (ошибки, front + back). Продуктовой аналитики нет.
- Язык интерфейса: только русский.

## Вне MVP (post-MVP, в порядке примерно по ценности)

Пользовательские фильтры; канбан; календарь; статистика и достижения; шаблоны; комментарии; совместные списки с назначением задач; помодоро; диапазоны дат start–end и длительность; напоминания привычек; email-напоминания и ежедневная сводка; импорт/экспорт (CSV/JSON); подписка iCal; офлайн-режим; EN-локализация; timeline; матрица Эйзенхауэра.

## Никогда (для этого проекта)

Голосовой ввод, location-напоминания, двусторонняя синхронизация Google/Outlook Calendar, интеграции третьих лиц (Zapier/IFTTT), публичный API.
