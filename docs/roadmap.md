# Plana — дорожная карта MVP (M1–M9)

Локальная разработка до деплоя: весь MVP собирается и проверяется локально (docker-compose Postgres + `pnpm dev`), деплой — после M9 по `docs/deploy.md`.

Правила для каждого этапа: полный зелёный прогон (`pnpm format && pnpm lint && pnpm typecheck && pnpm test && pnpm build`), e2e-тесты на новый функционал, ручной smoke в браузере, conventional commit в `develop`.

| Этап | Содержание                                                                                                                                                                                                   | Статус   |
| ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------- |
| M1   | БД (16 таблиц) + auth email/пароль (JWT 15м + refresh 30д с ротацией) + `/v1/me` + тема (system/light/dark) + скелет web (FSD, guard, формы)                                                                 | ✅ готов |
| M2   | Папки/списки/секции: CRUD api + сайдбар UI (дерево, Inbox, умные списки-заглушки), drag&drop позиции `position` шаг 1024                                                                                     | ✅ готов |
| M3   | Задачи: CRUD + подзадачи + list view (группировка по датам/спискам) + умные списки (Сегодня, Завтра, Неделя, Входящие, Все) + quick-add с разбором дат на русском                                            | ✅ готов |
| M4   | Повторяющиеся задачи: RRULE-движок (день/неделя/месяц/год), `dueDate` = следующее вхождение, история в `task_completions`                                                                                    | ✅ готов |
| M5   | Теги (CRUD + привязка), поиск (pg_trgm), корзина (30 дней, восстановление), массовые операции, drag&drop задач                                                                                               | ✅ готов |
| M6   | Трекер привычек: CRUD привычек + ежедневные отметки + календарь-стрик                                                                                                                                        | ✅ готов |
| M7   | Вложения: загрузка/скачивание файлов, storage-адаптер (локальная папка для dev, S3-совместимый для прода), лимиты по размеру/типу                                                                            |          |
| M8   | Web-push: подписки (VAPID), напоминания как offset от времени задачи, воркер отправки, PWA-манифест + service worker                                                                                         |          |
| M9   | Горячие клавиши, command palette, полировка UI, Google OAuth (после получения кредов от владельца)                                                                                                           |          |
| DS   | Дизайн-система (вне нумерации M1–M9, между M6 и M7): Tailwind v4 + motion + Storybook + Onest, токены из finnn с рефакторингом, контраст WCAG AA, миграция всех компонентов — `docs/design/design-system.md` | ✅ готов |

Google OAuth из скоупа M1 не исключён: схема БД (`oauth_accounts`) и api.md уже его описывают, включаем в M9, когда появятся клиентские креды.
