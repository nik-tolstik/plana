# TickTick — каталог возможностей и скоуп для Plana

Дата исследования: 2026-10-09. Источники: [ticktick.com/features](https://ticktick.com/features), [ticktick.com/upgrade](https://ticktick.com/upgrade), [help.ticktick.com](https://help.ticktick.com/articles/7054286604315131904), обзоры (The Digital Project Manager, Lifestack, ClaroCal).

Статусы финализированы по решениям владельца 2026-10-09 (см. `docs/decisions.md`), канонический скоуп — в `docs/mvp-scope.md`.

Обозначения в колонке «Plana»:

- ✅ — входит в MVP
- ⏸ — post-MVP (не входит)
- ❌ — не делаем

## 1. Задачи — ядро

| Возможность TickTick                      | Детали / лимиты free-плана                                                          | Plana                       |
| ----------------------------------------- | ----------------------------------------------------------------------------------- | --------------------------- |
| CRUD задач, отметка выполнения            | заголовок, описание, завершение/возврат                                             | ✅                          |
| Описание задачи                           | поддержка Markdown                                                                  | ✅                          |
| Приоритет                                 | High / Medium / Low / None                                                          | ✅                          |
| Дата выполнения                           | дата, время, «весь день»                                                            | ✅                          |
| Диапазон дат (start–end) и длительность   | duration — premium у TickTick                                                       | ⏸                           |
| Повторяющиеся задачи                      | ежедневные/еженедельные/… + кастомные правила: интервалы, дни недели, конец повтора | ✅                          |
| Подзадачи (checklist)                     | до 19 подзадач на задачу в free                                                     | ✅                          |
| Теги                                      | мульти-теги, свой порядок                                                           | ✅                          |
| Закреплённые (pinned) задачи              |                                                                                     | ✅                          |
| Быстрый ввод с NLP-парсингом дат          | «завтра в 17», «каждый пн» → дата/повтор                                            | ✅ (русский язык)           |
| Ручной drag&drop порядок + автосортировка | по дате / приоритету / названию                                                     | ✅                          |
| Массовые операции (multi-select)          |                                                                                     | ✅                          |
| Корзина                                   | удалённые хранятся, восстановление                                                  | ✅                          |
| Прогресс выполнения задачи (%)            |                                                                                     | ⏸                           |
| Вложения (файлы)                          |                                                                                     | ✅ (Railway Object Storage) |
| Шаблоны задач и списков                   |                                                                                     | ⏸                           |
| Локация задачи, напоминания по месту      | mobile-only                                                                         | ❌                          |
| Голосовой ввод                            |                                                                                     | ❌                          |

## 3. Представления

| Представление       | Детали / free-план                                 | Plana                               |
